# PRDKit Non-Goals

PRDKit is NOT:
- A Cursor/Claude Code/Codex competitor
- A low-code or no-code platform
- A visual drag-and-drop builder
- A full ERP or CRM generator
- A microservice orchestration framework
- A multi-agent framework
- A deployment platform (Vercel, Railway)
- A cloud provider
- A UI component library
- A code generation tool (PRDKit generates architecture, not implementation code)

PRDKit IS:
- Architecture intelligence engine
- Business-to-system translator
- AI coding tool handoff generator
- Domain-aware blueprint factory

When to say NO:
- "Can it generate React components?" → No. That's Cursor/Codex job.
- "Can it deploy my app?" → No. That's Vercel/Railway job.
- "Can it replace my architect?" → No. It augments, not replaces.
- "Can it generate the full application?" → No. It generates the blueprint. AI tools generate code.
