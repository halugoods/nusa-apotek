# NUSA v2.2.0+52 — Changelog

> **PENTING:** backup cloud sekarang otomatis & senyap. Data Anda tetap aman
> di akun Google — tidak ada lagi tombol backup manual yang wajib ditekan.

## 🆕 Fitur Baru

1. **Manual Item di Kasir** — tombol **"+"** di samping kategori. Kasih
   layanan/jasa dadakan (antar jemput, ongkir, biaya delivery, jasa angkut,
   turun mesin, dll) langsung dari layar kasir tanpa harus membuat produk
   dulu. Item manual tidak memotong stok.
2. **Pinpad Kasir Opsional** — bisa dimatikan dari Pengaturan → Keamanan.
   Saat mati, kasir buka fitur & buka kasir tanpa PIN (login tetap butuh
   PIN).
3. **Auto Cloud Sync** — data tersinkron otomatis ±6 detik (saat online) ke
   cloud Google Anda, dan diterima otomatis saat aplikasi dibuka. Tidak ada
   dialog/reminder. Kalau dua perangkat kebetulan edit bersamaan, data
   terbaru yang menang — yang lama tetap disimpan sebagai file snapshot
   (`conflict_*.sqlite`, terlihat di Pengaturan). **Tidak ada data yang
   hilang.**
4. **Izin Aplikasi Sekali** — setelah setup, ditanya sekali untuk izin
   kamera, notifikasi, penyimpanan & Bluetooth. Bisa dilewati, diatur
   lagi lewat Pengaturan.
5. **Pengaturan Struk** — barcode di struk dihapus; pengaturan **logo &
   footer struk** pindah ke Pengaturan → Pengaturan Struk (tidak lagi
   tersembunyi di pengaturan printer).
6. **Barcode di Form Produk** — scan kamera **dan** input manual langsung
   di form produk. Input manual di dialog scan (Kasir/Produk/Stok) dihapus
   supaya tidak salah scan.
7. **Update Dalam Aplikasi** — lonceng di dashboard menampilkan badge saat
   ada versi baru. Klik → lihat info update → **Download & Update** langsung
   dari aplikasi (dengan progress), lalu instal otomatis. Tidak perlu buka
   browser.

## Cara Pasang

Unduh APK varian sesuai usaha Anda, lalu **install di atas versi lama**
(File → Install, atau klik APK di HP). Data tetap aman. Untuk memakai Auto
Cloud Sync, pastikan aplikasi terhubung internet saat pertama dibuka.
